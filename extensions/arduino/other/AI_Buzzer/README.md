# AI 无源蜂鸣器插件

该插件适用于 `arduinoEsp32S3`，可通过无源蜂鸣器播放指定频率，也可调用随插件附带的 ESP32 音乐库播放内置旋律。

## 接线

将无源蜂鸣器的信号线接到积木中指定的 GPIO 引脚，另一端接 GND。工具箱中的默认 GPIO 为 `2`，如实际接线不同，请在初始化、播放和停止积木中使用相同的实际引脚编号。

## 积木功能

| 积木 | 用途 |
| --- | --- |
| 初始化无源蜂鸣器 | 初始化音乐播放器并指定蜂鸣器 GPIO。 |
| 播放指定频率 | 通过 ESP32 内置 LEDC 接口播放频率和时长可设的音调。 |
| 停止无源蜂鸣器 | 停止所选 GPIO 的音调输出。 |
| 播放内置音乐 | 通过 `musicESP32` 库以非阻塞方式播放附带旋律；播放期间仍可继续处理 MCP 指令。 |
| MCP 服务积木 | 与其他 AI 插件一致，可供 AIBot 注册、识别、读取参数和响应蜂鸣器服务。 |

## 内置旋律

内置旋律由用户提供的 `ESP32_music_lib` 实现，包括：生日快乐、俄罗斯方块、欢乐颂、圣诞旋律、超级玛丽和星球大战。插件仅保留 `lib/ESP32_music_lib`，音调输出使用 ESP32 内置 LEDC 接口。

## 注意事项

* 无源蜂鸣器可播放不同频率；有源蜂鸣器通常只能开关，无法正确演奏旋律。
* 同一时刻建议仅运行一个旋律或音调命令。
* 内置旋律使用 `millis()` 时间戳和后台状态任务推进，不会阻塞主程序；“停止无源蜂鸣器”可立即中断当前旋律。
